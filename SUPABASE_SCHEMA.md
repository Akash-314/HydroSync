## 2. Storage Buckets

1. **`public-assets`** (Public: `true`)
   - Size limit: 10 MB
   - Allowed MIME: `image/jpeg`, `image/png`, `image/webp`, `image/svg+xml`, `application/pdf`
2. **`project-media`** (Public: `true`)
   - Size limit: 15 MB
   - Allowed MIME: `image/jpeg`, `image/png`, `image/webp`, `image/svg+xml`
3. **`gallery`** (Public: `true`)
   - Size limit: 15 MB
   - Allowed MIME: `image/jpeg`, `image/png`, `image/webp`
4. **`application-attachments`** (Public: `false`)
   - Size limit: 25 MB
   - Allowed MIME: `application/pdf`, `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
   - Access: Restricted to temporary 3600-second HMAC signed URLs generated by authorized administrators.
